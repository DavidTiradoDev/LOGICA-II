# Estructuras de datos en Python

Ejemplos sencillos, un archivo por tema. Cada archivo se ejecuta solo.

## Lineales (los datos van uno detras de otro)

| Archivo | Tema | Como funciona |
|---|---|---|
| `lineales/01_arreglo.py` | Arreglo | Tamaño fijo, acceso por posicion |
| `lineales/02_lista_enlazada.py` | Lista enlazada | Cada elemento apunta al siguiente |
| `lineales/03_pila.py` | Pila | Ultimo en entrar, primero en salir (LIFO) |
| `lineales/04_cola.py` | Cola | Primero en entrar, primero en salir (FIFO) |

## No lineales (jerarquias o conexiones)

| Archivo | Tema | Como funciona |
|---|---|---|
| `no_lineales/05_arbol.py` | Arbol | Jerarquia de padres e hijos |
| `no_lineales/06_grafo.py` | Grafo | Nodos conectados entre si |
| `no_lineales/07_tabla_hash.py` | Tabla hash / mapa | Pares clave -> valor |
| `no_lineales/08_conjunto.py` | Conjunto | Elementos sin repetir |

## Como ejecutar

Desde la carpeta `estructuras_de_datos`:

```bash
python3 lineales/01_arreglo.py
python3 lineales/02_lista_enlazada.py
python3 lineales/03_pila.py
python3 lineales/04_cola.py
python3 no_lineales/05_arbol.py
python3 no_lineales/06_grafo.py
python3 no_lineales/07_tabla_hash.py
python3 no_lineales/08_conjunto.py
```
